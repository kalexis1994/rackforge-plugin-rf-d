## Integridad de los intentos

En el intento02 el comando repetido escribió sobre el path del export fallido de modo común; no se guardó hash previo de ese primer export. El archivo conservado es del replay y no se afirma identidad con el primero. Esta limitación de evidencia se mantiene abierta para ese intento. Antes del banco11 el helper se corrige para copiar/hashing de cualquier export fallido antes de repetir el comando. Las nueve escenas admitidas del banco final no tienen replays; se conserva cada original y se liga por hash.

La API de semilla devuelve un vector no finito para entradas no finitas/fuera de ±40 V o límites de rail invertidos (V−+1.63−0.65 > V+−1.63+0.65). `dc` lo rechaza mediante Result antes de evaluar el circuito; nunca se ejecuta clamp con bounds inválidos. Es una restricción del arranque analítico. Probar NaN/infinito/exceso por cada pin y rieles invertidos; los casos nominales no cambian. Banco12 liga esta protección previa al solver final.
